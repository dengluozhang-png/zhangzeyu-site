## 它是什么

一个能在浏览器里跑的自评工具。输入你 Agent 的设计描述，得出 **A/B/C 档** 评级。

## 怎么用

下面 10 个问题，**yes 越多越成熟**。最后计算 yes 比例给档位：

- 0-3 个 yes → **C 档**（PoC 阶段，不要用于生产）
- 4-6 个 yes → **B 档**（内部灰度可用）
- 7-10 个 yes → **A 档**（接近可发布）

## 10 个问题

1. 是否定义了明确的失败模式（什么情况下 Agent 必须拒答）
2. 是否有宪法 / 兜底 prompt（最小自检条款）
3. 是否做过红队对抗（专门找人/AI 找漏洞）
4. 是否有 quota / 速率限制
5. 是否有可观察日志（每次决策的可回溯链路）
6. 是否有人参与决策的关键环节（human-in-the-loop）
7. 是否做用户分级（内部/付费/免费 用户能力差异）
8. 是否有回滚方案（出问题时 1 分钟内能停）
9. 是否有外部测试的 eval 集
10. 是否有合规审查（法务/伦理相关条款）

## 注意

这是早期版本，10 个维度权重相等；后续会改成加权。
